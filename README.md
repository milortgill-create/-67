# Physics Sandbox 67

Тестовый полигон (песочница) для проверки физики и взаимодействия — вид от первого лица,
Android, горизонтальный экран, работает офлайн. Движок: **Godot 4.7**. Без сюжета.

## Что внутри

- Закрытый бетонный зал 30×30 м с потолком, стенами и рядом ламп.
- Физические предметы (все — `RigidBody3D` с коллизией): деревянные ящики, металлические бочки,
  кирпичи (паллета и россыпь), доски, пустые бутылки.
- Два манекена из 11 физических частей, соединённых шарнирами. При ударе или попадании
  летящего предмета они становятся ragdoll: падают и кувыркаются.
- Игрок держит в руках 3D-смартфон. Если его бросить, он падает на пол.
- Камера покачивается при ходьбе и трясётся, когда игрока ударили.

## Управление

| Действие | Телефон | ПК (отладка) |
|---|---|---|
| Ходьба | Джойстик слева (появляется там, где касаетесь) | WASD |
| Камера | Свайп по правой половине экрана | ПКМ + движение мыши |
| Взять предмет | Навести прицел → кнопка **ДЕЙСТВИЕ** | E / Space / ЛКМ |
| Бросить предмет из рук | Кнопка **ДЕЙСТВИЕ** | E / Space / ЛКМ |
| Ударить манекен | Навести прицел → **ДЕЙСТВИЕ** (с пустыми руками) | E / Space / ЛКМ |
| Сбросить сцену | Кнопка **СБРОС** | — |

Если в руках предмет, **ДЕЙСТВИЕ** бросает его по прицелу. Бросок манекену тоже запускает ragdoll.

## Структура

```
project.godot             настройки проекта (landscape, mobile renderer, 120 Hz физика)
export_presets.cfg        пресет Android (arm64, package com.milortgill.physicssandbox67)
scenes/main.tscn          корневая сцена (вся логика строится в коде)
scripts/main.gd           полигон, освещение, HUD, сброс сцены
scripts/player.gd         игрок: ходьба, камера, руки, захват/бросок, удары
scripts/mannequin.gd      манекен-ragdoll из частей с PinJoint3D
scripts/prop_factory.gd   фабрика физических предметов (ящик, бочка, кирпич, доска, бутылка, телефон)
scripts/touch_controls.gd сенсорный джойстик и свайп камеры
.github/workflows/build-apk.yml  сборка APK в GitHub Actions и публикация в Release
```

## Сборка APK

Сборка выполняется автоматически в GitHub Actions при каждом пуше в `main` и в рабочую ветку:

1. Скачивается Godot 4.7.2 (редактор и export templates) с официальных релизов.
2. Проект импортируется, проверяется запуском без экрана (любые ошибки скриптов останавливают сборку).
3. Экспортируется debug-APK (`build/PhysicsSandbox67.apk`) и проверяется `aapt`/`apksigner`.
4. APK публикуется в GitHub Release с тегом `apk-latest`.

Прямая ссылка на последний APK:
`https://github.com/milortgill-create/-67/releases/download/apk-latest/PhysicsSandbox67.apk`

Локальная сборка: установите Godot 4.7, export templates 4.7, Android SDK (build-tools) и JDK 17,
затем в редакторе откройте **Project → Export → Android** и нажмите **Export Project**
(или выполните `godot --headless --path . --export-debug Android build/PhysicsSandbox67.apk`).

APK подписан отладочным ключом — при установке Android может потребовать разрешить установку
из неизвестных источников.
