# Physics Sandbox 67

Тестовый полигон (песочница) для проверки физики и взаимодействия — вид от первого лица,
Android, горизонтальный экран, работает офлайн. Движок: **Godot 4.7**. Без сюжета.

## Что внутри

- Закрытый бетонный зал 30×30 м с потолком, стенами и рядом ламп.
- Предметы с реалистичной массой: бутылка 0.5 кг, доска 3 кг, ящик 15 кг, металлическая бочка 40 кг,
  кирпич 2.5 кг, смартфон 0.19 кг.
- **Разрушение:** бутылки бьются о пол и о предметы (при скорости удара > 3 м/с), ящики ломаются
  (> 6 м/с). Эффект — частицы GPUParticles3D и физические осколки, которые исчезают через несколько секунд.
- **Захват физический:** предмет в руках остаётся RigidBody3D и сталкивается со стенами и предметами.
  Коллизия с игроком отключается на время захвата и броска, поэтому брошенный предмет не наносит урон.
- **Манекены из 11 капсульных частей** с шарнирами Generic6DOF и пределами углов: локти и колени сгибаются
  только в одну сторону, плечи и бедра — в естественном диапазоне. Части сталкиваются друг с другом,
  кроме соединённых напрямую. Видны суставы, лицо, ступни и кулаки.
  - Лёгкий удар (толчок, касание) только отшатывает манекен и заставляет схватиться за место удара
    (удар в голову — обе руки к лицу).
    Падение (ragdoll) — только от сильного удара (энергия выше порога).
  - Вставание по ключевым кадрам: упор на руки → колени → полуприсед → стойка. Манекен не встаёт
    сквозь стены: перед подъёмом проверяется свободное место.
  - **Манекен №1 (пассивный):** сбитый, встаёт, когда игрок подходит ближе 4 м. Не атакует.
  - **Манекен №2 (агрессивный):** замечает игрока в радиусе 9 м, идёт к нему и бьёт (8 урона).
    Сбитый встаёт сам через несколько секунд.
- Игрок с HP (100). Удары манекенов и летящие предметы наносят урон и трясут камеру.
- **Травмы и иконка тела:** в левом нижнем углу — 2D-силуэт человечка. Удар, падение или урон
  подсвечивают красным пострадавшую часть тела (голова, корпус, руки, ноги). Травмы постепенно заживают.
- **Рюкзак (кнопка РЮКЗАК):** сетка из 12 слотов. Нажмите на предмет — появится табличка с описанием
  и весом; её можно достать. Предмет из рук кладётся кнопкой «Положить». В рюкзак не помещаются
  громоздкие предметы (бочка, ящик 80 см, длинная доска) и предметы тяжелее 20 кг.
- **Вес:** чем тяжелее рюкзак и предмет в руках, тем медленнее ходьба (до 45% скорости).
- **Модели предметов:** ящики с досками и гвоздями и обвязкой, бочки с металлическими обручами,
  бутылки с этикетками и горлышком, доски с годовыми кольцами, кирпичи, смартфон с экраном.
- Руки: детализированные модели кистей (ладонь, фаланги пальцев с суставами, ногти, большой палец)
  и анимация удара: замах и удар рукой (сильнее с разбега).
- Смартфон в руках. Если его бросить, он падает на пол.

## Управление

| Действие | Телефон | ПК (отладка) |
|---|---|---|
| Ходьба | Джойстик слева (появляется там, где касаетесь) | WASD |
| Камера | Свайп по правой половине экрана | ПКМ + движение мыши |
| Взять предмет | Навести прицел → кнопка **ДЕЙСТВИЕ** | E / Space / ЛКМ |
| Бросить предмет из рук | Кнопка **ДЕЙСТВИЕ** | E / Space / ЛКМ |
| Ударить манекен | Навести прицел на манекен (до 2.6 м) → **ДЕЙСТВИЕ** с пустыми руками | E / Space / ЛКМ |
| Открыть рюкзак | Кнопка **РЮКЗАК** | — |
| Сбросить сцену | Кнопка **СБРОС** (сбрасывает и рюкзак, и травмы) | — |

Если в руках предмет, **ДЕЙСТВИЕ** бросает его по прицелу. Бросок манекену тоже запускает ragdoll.

## Структура

```
project.godot             настройки проекта (landscape, mobile renderer, 120 Hz физика)
export_presets.cfg        пресет Android (arm64, package com.milortgill.physicssandbox67)
scenes/main.tscn          корневая сцена (вся логика строится в коде)
scripts/main.gd           полигон, освещение, HUD, сброс сцены
scripts/player.gd         игрок: ходьба, камера, руки, захват/бросок, удары
scripts/mannequin.gd      манекен: капсульные части, шарниры с пределами, ИИ, встать/бить
scripts/prop_factory.gd   фабрика предметов с реальными массами
scripts/prop_body.gd      PropBody: физический предмет, поломка при ударе
scripts/shatter_fx.gd     эффекты разрушения (частицы и осколки)
scripts/body_icon.gd      2D-иконка тела в HUD с подсветкой травм
scripts/backpack_ui.gd    окно рюкзака: сетка слотов и табличка предмета
scripts/touch_controls.gd сенсорный джойстик и свайп камеры
.github/workflows/build-apk.yml  сборка APK в GitHub Actions и публикация в Release
```

## Сборка APK

Сборка выполняется автоматически в GitHub Actions при каждом пуше в `main` и в рабочую ветку:

1. Скачивается Godot 4.7.2 (редактор и export templates) с официальных релизов.
2. Проект импортируется, проверяется запуском без экрана (любые ошибки скриптов останавливают сборку).
3. Экспортируется debug-APK (`build/PhysicsSandbox67.apk`) и проверяется его структура.
4. Гейм-плейный самотест (`--selftest`): захват, бросок, удар, падение, вставание, бой, сброс.
   Результаты выводятся как аннотации в GitHub Actions.
5. APK публикуется в GitHub Release с тегом `apk-latest`.

Прямая ссылка на последний APK:
`https://github.com/milortgill-create/-67/releases/download/apk-latest/PhysicsSandbox67.apk`

Локальная сборка: установите Godot 4.7, export templates 4.7, Android SDK (build-tools) и JDK 17,
затем в редакторе откройте **Project → Export → Android** и нажмите **Export Project**
(или выполните `godot --headless --path . --export-debug Android build/PhysicsSandbox67.apk`).

APK подписан отладочным ключом — при установке Android может потребовать разрешить установку
из неизвестных источников.
